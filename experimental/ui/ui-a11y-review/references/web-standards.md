# Optional web-specific reference

The [WCAG 2.2 Recommendation](https://www.w3.org/TR/WCAG22/) is the normative authority. The linked WCAG Understanding pages are informative explanations, and the APG link is informative pattern guidance; consult the authoritative sources when deciding applicability. Do not treat this short reference as full WCAG coverage.

- Consistent identification and navigation: https://www.w3.org/WAI/WCAG22/Understanding/consistent-identification.html and https://www.w3.org/WAI/WCAG22/Understanding/consistent-navigation.html (WCAG 2.2 SC 3.2.4 and 3.2.3, Level AA; same-function components and repeated navigation within the applicable set of web pages).
- Reflow: https://www.w3.org/WAI/WCAG22/Understanding/reflow.html (WCAG 2.2 SC 1.4.10, Level AA: without loss of information or functionality and without two-dimensional scrolling for content that scrolls vertically at a 320 CSS-pixel-equivalent width or content that scrolls horizontally at a 256 CSS-pixel-equivalent height, except content needing two-dimensional layout).
- Resize text: https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html (WCAG 2.2 SC 1.4.4, Level AA: 200% text resizing through a supported text-scaling mechanism, which may be browser page zoom; record this evidence separately from Reflow).
- Text spacing: https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html
- Text contrast: https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html (normal/large text and stated exceptions; do not round a failing ratio up).
- Target size minimum: https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html (WCAG 2.2 SC 2.5.8, Level AA; pointer-input targets of 24 by 24 CSS pixels with the source's alternatives/exceptions; not a blanket 44-pixel rule).
- Modal interaction: https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/ (APG pattern guidance, not normative; use applicable [WAI-ARIA dialog semantics](https://www.w3.org/TR/wai-aria-1.2/#dialog) and HTML requirements separately).
