# Final editing guide

Use this reference only for `final` and `full` modes.

Apply visual guidance only when the output medium supports it.

## Hierarchy and density

- Use informative sentence-case headings with a consistent hierarchy.
- Avoid more than three heading depths in ordinary documents.
- Split visually dense paragraphs only where the thought changes.
- Use one blank line between paragraphs and more space above a heading than below it when rendered layout is controllable.
- Keep body text left-aligned and avoid full-width prose on large displays.

## Lists, tables, and references

- Keep list items parallel and list nesting shallow.
- Use tables only for stable comparisons; do not force causal narratives into cells.
- Expand non-canonical acronyms on first use.
- Check links, references, captions, identifiers, and status labels for consistency.
- Expose unresolved placeholders instead of silently deleting or completing them.

## Emphasis and accessibility

- Use bold for a short local rule, term, or critical contrast, not whole paragraphs.
- Use colour only for status or navigation and never as the sole carrier of meaning.
- Avoid decorative gradients, banners, separators, empty callouts, emojis, and repeated conclusions.

Return the complete final-edited document and a short list of unresolved publication issues. Do not change technical content to make the document look complete.
