# Structural editing guide

Use this reference only for `structural` and `full` modes.

## Reader path

- Follow the selected canonical profile's required early reader path.
- Put prerequisites before dependent conclusions.
- Give each section a recognisable reader question and each paragraph one semantic job.
- Separate current state, proposal, rationale, consequence, rollout, and uncertainty when combining them obscures their relationship.
- Allocate more detail to uncertain, dangerous, irreversible, or disputed material than to routine mechanics.

## Paragraphs and evidence

- Start a new paragraph when the actor, time period, alternative, certainty, argument direction, or normative status changes.
- Keep evidence next to its claim and qualifications next to the language they limit.
- Preserve useful layered detail: a concise summary may precede justified detail.
- Do not merge similar statements whose scope, modality, certainty, or evidence differs.

## Profile-sensitive content

- Use the canonical profile requirements to decide whether alternatives, acceptance criteria, chronology, corrective actions, or a focused requested change are required.
- For decision documents, retain serious alternatives and doing nothing. If required analysis is missing from approved material, return a substantive finding.
- For incidents, preserve the distinction between chronology, trigger, contributing condition, failed control, amplifier, detection gap, recovery, and corrective action.
- For products, keep user problem, required behaviour, acceptance, permissions, failure paths, and implementation choices distinct.
- For comments, keep one located, falsifiable, proportionate issue.

## Lists and tables

- Use lists for parallel requirements, alternatives, examples, or questions.
- Use prose for causal sequences and arguments.
- Use tables only when readers compare stable fields across items.
- Avoid deep nesting and decorative callouts.

If reordering exposes missing reasoning or an unresolved substantive conflict, stop and return the finding; do not continue to line editing.
