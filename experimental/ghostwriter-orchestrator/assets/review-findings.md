# Review findings

Working output only. Never append this template to a requested article.

Draft version or identifier:
Review: reader / fidelity / targeted recheck.
Context: isolated packet / same-context self-review / isolation unverified.

For each real finding:

- Location and exact draft quote:
- Category: missing meaning / altered meaning / unsupported addition /
  conversation leakage / connection / density / grammar / evidence gap.
- Severity: material (meaning or understanding changes) / local (limited repair).
- Evidence: source anchor for fidelity; exact reader difficulty for reader review.
- Repair needed: what must change, without inventing missing substance.
- For a comprehension defect, when useful: the question the text should answer
  for this reader, and what wording currently supports or fails to support it.

Do not require a fixed number of findings. Distinguish observed defects from
uncertain suspicions. Return no findings when justified. The reader reviewer
may first give a short reconstruction of the argument visible in the draft.
