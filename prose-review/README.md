# prose-review

A reusable orchestrator skill for diagnosing and minimally editing generic, over-regularised, assistant-like prose.

Contents:
- `SKILL.md` — orchestrator and convergence loop.
- `facets/argument-shape.md` — argument architecture, symmetry, judgement, conclusions.
- `facets/semantic-density.md` — semantic progress, repetition, deletion-first editing.
- `facets/voice-rhythm.md` — unjustified regularity and author-voice drift.
- `facets/specificity-epistemics.md` — bounded claims, mechanisms, evidence, calibrated uncertainty.
- `facets/stochastic-parrot.md` — generic synthesis and fluent prose without subject-specific thought.
- `EVALUATION.md` — five-agent adversarial evaluation and changes made.

The skill deliberately does not optimise for AI-detector scores. It optimises for reader experience, meaning preservation, and authentic authorship.
